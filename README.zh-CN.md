# Keymen 的联想记忆研究

研究作者与项目维护者：[Keymen（keymen6303-lgtm）](https://github.com/keymen6303-lgtm)。

[English](README.md) · [结果与边界](RESULTS.md) · [已有研究与引用](REFERENCES.md)

这是我的联想记忆研究项目，研究一个具体问题：**复习哪些内容、用什么方式判断“见过”、复习副本发生怎样的变形，会怎样影响记忆和误认？**

我们用可计算的人工联想记忆模型，把“从残缺线索找回具体旧样本”和“把相似但没见过的输入误认为旧内容”分开测量。复习组的存储与事件预算一致；先用20个校准种子确定判断阈值，再用40个不同确认种子评价。

目前最明确的结果是：去掉精确旧副本，并没有解决主要判断方式的误认。精确副本与等幅独立方向副本的相似误认率都为 **34.50%**，预先规定的联合改善标准没有通过。换成最大相似度判断后，某些变形源的误认会大幅减少，但旧内容命中也下降，而且这是探索性结果。残缺线索恢复具体旧实例的成功率仍只有约 **4.5%**。

这是一套可以检查、复现和改进的研究工具，包含失败结果；没有证明人脑的新机制，也没有证明发明了更好的通用记忆算法。基本模型、能量引导回放思路和联合回忆/识别任务已有前人工作，贡献在于当前有限条件下的控制实验和诊断。

## 运行

本地验证使用Python 3.12。无需GPU，也无需下载人体数据。

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -q
python demo.py
```

`demo.py`只跑一个合成种子，用来检查能否运行，不代表完整确认结论。完整实验分别运行：

```sh
python run_energy.py
python run_readout.py
python run_fidelity.py
```

这三个入口可以独立运行。第七阶段还包含九组规模/相关性条件和2000次原文方程复现旋转，完整实验比示例大，需要几分钟及保存表格、缓存的空间。

新结果写到`outputs/energy`、`outputs/readout`、`outputs/fidelity`，缓存写到`work/`。已有冻结结果或断点续跑需加`--resume`。源码、协议或参数发生变化，应使用新的工作副本，不能套用原冻结阈值。报告和绘图为中文；非macOS系统可能需要配置中文字体。`requirements-reproduction.txt`记录原结果所用精确依赖版本；宽版本范围不保证逐位一致。跨平台是否通过以实际CI状态为准。

## 文件与解释

本项目呈现我的研究第七至九阶段：闭式模型复现与能量选择、固定模型的四种判断读出、三种回放源控制。`*_protocol.md`保留原运行前本地协议，但不是公开预注册；`reference_results/`是原结果快照，独立于新运行输出；`outputs/literature/`保留查新记录与实际读取边界。包含20项针对这些实验的科学与工程测试；完整第九阶段已在本地重跑复现，Linux与macOS的20项检查和示例也已通过[自动测试](https://github.com/keymen6303-lgtm/memory-replay-lab/actions/runs/37976039027)。

模型显式存储向量和质量，复习用增加支持点与质量表示，不是突触可塑性或网络训练。无回放组预算较低，只能作参考。相同旋转源会与已有支持点重复，独立变形源会改变相关性；不能把源变化说成只改变精度。置信区间以种子为单位且为近似bootstrap；未通过不等于证明完全无差异。
