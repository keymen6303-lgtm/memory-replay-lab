# Contributing

Run `python -m pytest -q` and `python demo.py` before proposing a change. Describe which behavior or scientific invariant the change affects. Report failures as well as successes.

Preserve the original protocols and reference snapshots. For a new study, record a separate protocol, new seeds and a fresh output/cache location before inspecting confirmation results. Check primary prior work first, document reading scope, and explain the additional question. Label exploratory comparisons clearly. Never silently tune the original confirmation study or present a changed model as an exact reproduction.

Project author and maintainer: [Keymen](https://github.com/keymen6303-lgtm). Review model changes against the cited equations and scientific invariants. A new claim should be supported by reproducible results and a comparison with prior work.
